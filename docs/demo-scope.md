# Demo Scope

This demo presents product capability, not production implementation.

## Included

- Static UI shell
- Mock data stored in JavaScript files
- Fictional operating scenarios
- Local-only preview
- Sanitized README and documentation

## Excluded

- Production repository history
- Back-end server code
- Database connections
- Real upload files
- Real contracts, material price sheets, budgets or employee data
- Real domains, IP addresses, account names, passwords, keys or certificates

## First Deliverable

The first deliverable is a local static preview that can be reviewed safely before any public GitHub repository is created.
